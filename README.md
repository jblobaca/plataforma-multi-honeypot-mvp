## Qué es (y qué no es)

Este repositorio es el **producto mínimo viable** del relato de valor: canvas, informe y un dashboard de Threat Intelligence con **datos de demostración**.

No despliega honeypots reales, no captura tráfico y no incluye procedimientos de ataque. El experimento de 30 días del plan se ejecutará solo en una red simulada de Intercert Latam, con autorización formal.

## Cómo correrlo en local

```bash
npm install
npm run dev
```
Abre http://localhost:3000
